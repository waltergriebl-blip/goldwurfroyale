# GitHub Upload

Dein GitHub-Name ist:

`waltergriebl-blip`

## Repository erstellen

1. Öffne GitHub.
2. Klicke auf `New repository`.
3. Name: `wuerfelduell`
4. Stelle es auf `Public`, wenn Netlify direkt darauf zugreifen soll.
5. Kein README anhaken, weil dieses Projekt schon eine README-Datei hat.
6. Repository erstellen.

## Dateien hochladen

1. Öffne dein neues Repository.
2. Klicke auf `uploading an existing file`.
3. Ziehe alle Projektdateien hinein.
4. Klicke auf `Commit changes`.

## Für Netlify

Wenn Netlify mit GitHub verbunden wird:

- Publish directory: `Webseite`
- Build command: leer lassen

Dann veröffentlicht Netlify nur die Webseite-Dateien.
