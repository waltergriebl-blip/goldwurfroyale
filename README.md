# Würfelduell

Dieses Projekt ist jetzt in zwei Bereiche getrennt.

## Webseite

Der Ordner `Webseite` enthält alles für Netlify:

- `index.html`
- `styles.css`
- `script.js`
- `manifest.webmanifest`
- `sw.js`
- `icons`

Wenn du die Webseite aktualisieren möchtest, lade den Inhalt von `Webseite` hoch.

## IOS-App

Der Ordner `IOS-App` enthält die Vorbereitung für eine spätere iPhone-App mit Xcode:

- `package.json`
- `capacitor.config.json`
- `IOS_APP_ANLEITUNG.md`

Die iOS-App nutzt die Spiel-Dateien aus dem Ordner `Webseite`.
